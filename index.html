In progress

Tochi Voice Gateway

Voice transcription backend for a mobile app

  • 15-minute JWTs
  • Rotating refresh credentials
  • Idempotent requests
  • Per-device quotas
  • Swappable speech providers

I built the backend that turns short voice recordings into transcripts and draft tasks. Devices register with the service, receive short-lived JWTs with rotating refresh credentials, then upload audio that is checked by file signature, size and duration before it reaches a speech provider. Idempotency keys prevent duplicate processing, and per-installation quotas, concurrency limits and an admin kill switch keep cost and load under control.

  • Node.js
  • Express.js
  • Prisma

Completed

Virtual Drug Screening and Molecular Docking Microservice

Computational drug discovery tooling, built with pharmacology in mind

  • About 20 seconds per docking job
  • Async job queue
  • Reproducible experiment history
  • Fully containerised

I built a virtual screening pipeline that pairs a Node.js and Express API gateway with a Python FastAPI compute service. Long docking jobs run through a Redis and BullMQ queue, with ligands and receptors prepared using RDKit, OpenBabel and Meeko and scored with AutoDock Vina. A PostgreSQL schema tracks jobs, ligand libraries and results so every experiment can be queried and reproduced.

  • Express.js
  • Python
  • FastAPI
  • Redis
